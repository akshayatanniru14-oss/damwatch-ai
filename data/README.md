# Contents of the file: /damwatch-ai/damwatch-ai/data/README.md

This directory contains data files used by the DamWatch AI application.

- **assets.geojson**: Contains hardcoded records of 12 real Indian dams/reservoirs, including their names, types, states, and geographical coordinates (latitude and longitude).

- **demo_cache/**: This folder contains sample JSON files representing different severity cases (low, medium, high) for demonstration purposes. These files can be used to test the application without needing a live API connection.

- **samples/**: This folder is intended for storing sample images. Please drop in real photos of the dams, canals, or reservoirs you wish to analyze. Ensure that the images are relevant to the inspection reports generated by the application.

Make sure to keep the structure organized and update the files as necessary to maintain the integrity of the data used in the application.
