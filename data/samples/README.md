# Contents of the file: /damwatch-ai/damwatch-ai/data/samples/README.md

This directory contains sample images for the DamWatch AI project. 

Included test images:

- `dam-failure-public-domain.jpg` - Teton Dam failure photo from [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Teton_Dam_failure.jpg), marked public domain.
- `erosion-public-domain.jpg` - Erosion photo from [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Erosion.jpg), marked public domain.

To add real photos for analysis, please follow these steps:

1. Place your images in this directory, ensuring they are in one of the supported formats: JPEG, PNG, or WEBP.
2. Name the images clearly to reflect the dam or reservoir they represent, as this will help in identifying them during analysis.
3. Ensure that the images are of good quality and clearly show the area of interest for inspection.
4. Update the demo cache files in `/data/demo_cache/` with the corresponding image paths if you want to include them in the demo mode.

Please ensure that the images are relevant to the inspections being conducted and adhere to the project's guidelines for visual evidence.
